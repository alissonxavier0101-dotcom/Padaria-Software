Permissão do Firestore

O Firestore do projeto padaria-sistema-6a6b4 precisa de regras liberadas para gravar a coleção insumos: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /insumos/{document=**} {
      allow read, write: if true;
    }
  }
}
